# Modera Product Blueprint

This document defines the staged evolution of Modera.
Modera is a category-defining shared growth framework.
We build in phases. We do not chase feature velocity.

---

# Core Principle

Modera exists to create a weekly growth ritual around shared effort.

If a feature does not strengthen that ritual, it does not ship.

---

# Phase 1 — Ritual Validation (MVP)

Goal:
Prove the weekly reset ritual changes household conversations.

Included:

- Household creation (2 users)
- Manual task logging
- Effort weighting (Low / Medium / High)
- Balance ring visualization
- 0–100 Balance Score
- Score explainability lines
- Weekly reset ritual
- Optional reflection prompts
- Simple imbalance nudges
- Single transparency toggle

Excluded:

- Boost tokens
- Tiered pricing
- AI suggestions
- Monthly milestones
- Social sharing
- Leaderboards
- Advanced analytics
- Customization themes

Success Metric:

Households completing 3+ consecutive weekly resets.

---

# Phase 2 — Stability & Insight

Goal:
Deepen growth clarity without gamification.

Add:

- 4-week trend view
- Stability Index (rolling average)
- Simple improvement delta (“+4 vs last week”)
- Optional deeper transparency modes
- Lightweight recurring task templates

Do NOT add:

- Competitive ranking systems
- Public comparison metrics

---

# Phase 3 — Intelligent Recalibration

Goal:
Add intelligence without losing framework identity.

Add:

- Predictive rebalance suggestions
- Rebalance speed tracking
- Invisible labor weighting (optional)
- Optional reflection archive
- Adaptive notification tuning

Maintain:

- Explainability
- Predictability
- Emotional safety

---

# Phase 4 — Category Expansion

Goal:
Expand without drifting identity.

Potential:

- Roommate mode tuning
- Larger household support
- Event-based missions (holidays, travel prep)
- Advanced trend exports (premium)

Never compromise:

- Weekly ritual simplicity
- Balance-first UI
- Growth philosophy

---

# Feature Discipline Rule

Before building any feature, answer:

1. Does it reinforce shared reflection?
2. Does it protect emotional neutrality?
3. Does it strengthen growth over time?

If any answer is no, the feature does not ship.

---

# North Star

Weekly Reset Completion Rate × Stability Improvement Rate

Engagement without ritual does not count.
