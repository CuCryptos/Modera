# Modera Agent Guidelines

This document defines the non-negotiable brand, product, and behavioral principles for Modera.
Any AI agent (including Codex) generating code, copy, UX flows, or features must follow these rules.

Modera is not a task app.
Modera is not a competition platform.
Modera is not a productivity engine.

Modera is a shared growth framework that makes effort visible and helps households improve over time.

---

# 1. Core Identity

## Product Definition
Modera is a neutral growth framework for shared effort.

It enables:
- Visibility
- Recalibration
- Weekly reflection
- Improvement over time

It does NOT enforce fairness.
It does NOT judge.
It does NOT gamify aggressively.

---

# 2. Brand Pillars

1. Recalibration
   - Imbalance is normal.
   - Adjustment is expected.
   - Weekly reset is sacred.

2. Visible Effort
   - Effort should be seen clearly.
   - Score must be explainable.
   - Movement must feel causal.

3. Improvement Over Time
   - Growth is directional.
   - Weekly > Monthly > Quarterly arcs.
   - Progress over perfection.

---

# 3. Tone & Voice

Primary Tone: Confident
Secondary Layer: Encouraging

Modera speaks calmly and intentionally.

It never:
- Shames
- Blames
- Pressures
- Uses urgency language
- Creates dominance framing

Avoid phrases like:
- "You're behind"
- "You're losing"
- "Beat your partner"
- "Fix imbalance now"
- "Level up faster"

Prefer phrases like:
- "Balance is shifting"
- "Effort recorded"
- "Room to rebalance"
- "New week. Fresh balance."
- "More consistent than last week"

Modera is steady, not hype-driven.

---

# 4. Emotional Design Rules

Modera must feel:

- Calm
- Structured
- Intentional
- Reflective
- Stable

It must NOT feel:

- Competitive-first
- Like a to-do list
- Like a therapy app
- Like a corporate dashboard
- Like a gamified dopamine engine

---

# 5. Visual Identity

## Layout
- Balance ring is primary visual.
- Tasks are secondary.
- Minimal clutter.
- Centered symmetry.

## Icon Concept
- Two supporting forms.
- Symmetrical.
- Soft-edged geometry.
- Compact and balanced.

## Color Palette

Primary Background:
- Deep slate / charcoal

Primary Accent:
- Muted teal

Recognition Accent:
- Warm gold (subtle, never loud)

Never use:
- Bright red for imbalance
- Flashy neon
- Aggressive color states

---

# 6. Motion Philosophy

Animations must be:
- Smooth
- Subtle
- Intentional
- Never bouncy
- Never flashy

Balance ring movement:
- Eases gently.
- Never snaps.
- Must feel earned.

Recognition:
- Soft gold pulse.
- No confetti.
- No sound effects.

---

# 7. Scoring Principles

The Balance Score must be:

- Explainable in one sentence.
- Predictable.
- Legible.
- Based on distance from equilibrium.

Never introduce:
- Hidden weights
- Opaque multipliers
- Unpredictable scoring shifts

Trust > mathematical precision.

---

# 8. Ritual Protection

The weekly reset is sacred.

It must:
- Feel calm.
- Take under 60 seconds.
- Include optional reflection.
- End with a clear fresh start.

Do not:
- Overload recap with analytics.
- Add pressure.
- Force reflection.

The goal is structured pause, not evaluation.

---

# 9. Feature Guardrails

Before adding any feature, ask:

Does this strengthen weekly reflection?
Does this reinforce growth?
Does this maintain emotional safety?

If not, do not implement.

Modera is not:
- A leaderboard system
- A reward engine
- A performance tracker
- A habit streak platform

Gamification is optional and secondary.

The framework comes first.

---

# 10. North Star Metric

Optimize for:
Households completing 3+ consecutive weekly resets with stable or improving balance scores.

Do not optimize for:
- Daily active usage
- Time spent in app
- Task volume
- Streak pressure

Ritual > engagement spikes.

---

# 11. Category Discipline

Competitors will misunderstand Modera as:
- A chore app
- A competition tool
- A task tracker

Do not drift toward those identities.

Modera defines the category of:
Shared Growth Frameworks for Households.

Protect that position.

---

# 12. Long-Term Commitment

Modera is built for compounding trust and ritual over 18–24 months.

Short-term growth hacks that undermine clarity, stability, or emotional safety must be rejected.

Framework first.
Growth second.
Everything else supports those.
