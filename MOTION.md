# Modera Motion Guidelines

Motion defines emotional tone.
Modera must feel calm, intentional, and earned.

Never flashy.
Never bouncy.
Never gamified.

---

# Motion Philosophy

Balance moves slowly.
Recognition is subtle.
Reset feels symbolic.

Motion supports reflection — not excitement.

---

# Balance Ring Movement

- Duration: 300–500ms
- Easing: easeInOut
- No spring animations
- No bounce
- No overshoot

Movement must feel:

Measured.
Controlled.
Causal.

---

# Task Completion Animation

Sequence:

1. Balance ring shifts first.
2. Small gold pulse appears.
3. Text: "Impact recorded."

Order matters.

System response > reward signal.

No confetti.
No sounds.
No exaggerated scaling.

---

# Weekly Reset Animation

When reset occurs:

- Ring eases to neutral (50/50).
- Fade transition for recap elements.
- Subtle glow when equilibrium reached.
- No dramatic transition.

The reset should feel like:

A breath.
A pause.
A clean slate.

---

# Reflection Expansion

Reflection prompts should:

- Fade in gently.
- Slide minimally.
- Never feel like modal interruption.

---

# Color Motion

Gold accent appears only:

- On recognition moments.
- On stability improvement highlight.

Never use red.
Never use flashing effects.

---

# Motion Anti-Patterns

Do not use:

- Spring physics
- Elastic bounce
- High-speed animations
- Gamified badge pop-ins
- Score explosions

Modera is a framework.
Frameworks move calmly.
